## Whalesay 🐳

The Docker whale is installed in this sandbox. Run `whalesay "your message"`
to make the whale say something — it's `cowsay` using the Docker whale as the
default cow. The `whalesay` command is on PATH at `/usr/local/bin/whalesay`;
the cowsay script and the `docker.cow` art live under `/usr/local/share/whalesay`.
No key or network needed — it works offline.
